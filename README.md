# Iris Flower Species Data Analysis Project

## 1. The problem or research question
How can we classify and understand iris flower species based on their physical measurements (such as petal length, petal width, and sepal length)?

## 2. Dataset source and usage permissions
The dataset used in this project is the classic Iris dataset, loaded directly via the Seaborn library. It is publicly available and open for educational and research use.

## 3. Methods and tools used
- **Programming Language**: Python
- **Libraries**: Pandas, Seaborn, Matplotlib, Scikit-learn
- **Methods**: Exploratory Data Analysis (EDA), Scatter Plot Analysis, and Boxplot Distribution Analysis.

## 4. Key findings and one limitation
- **Key Findings**: Petal length and petal width show a strong positive correlation and can effectively separate Setosa from Versicolor and Virginica species.
- **Limitation**: The dataset is relatively small and features only a single plant genus, making the findings non-generalizable to other botanical domains without further data.

## 5. Instructions for running the analysis
1. Clone the repository: `git clone https://github.com/LuoYawen-UM/data-science-project.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python analysis.py`
